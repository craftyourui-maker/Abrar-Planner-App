# Daymark

**What it is:** A mobile hobby planner. Daymark uses AI to shape realistic hobby sessions around a person's week, then celebrates every small win with XP, streaks and trophies. Tagline: "Make time for what makes you, you." Promise: "Grow a little, often."

**Who it's for:** Busy adults with several hobbies (guitar, running, painting, reading, cooking) who want steady progress without a rigid schedule. The demo persona is Alex Morgan, "Curious Maker", Level 8, member since March 2026.

**Core jobs:**
1. Onboard: pick hobbies, set pace and goals, choose available time, accept an AI starter plan.
2. Daily: see today's sessions and momentum, start a session, run it task by task, reflect afterwards.
3. Plan: create activities, have AI break an idea into timed tasks, edit sessions, rebalance the day.
4. Review: progress per hobby, consistency, highlights, rewards and trophies.
5. Control: notifications, AI assistance and privacy settings.

**Platform:** Mobile-first web app (412dp Android frame in the source design), Material 3.

**Brand commitments:** Material 3 Design Kit, Blue palette, Roboto, M3 components, expressive wavy progress indicators. Faithful to the Figma source with polish only; no rebrand. Gamification is encouraging, never punitive (streak nudges only when at risk; quiet hours respected).

**Data:** Demo data seeded for Alex, persisted in the browser, with a reset option. "Today" is fixed at Tuesday, October 6, 2026 so the seeded plan reads correctly.
